# 小程序画板 UI 结构标注（用户截图实测）

> 本文依据用户提供的 4 张小程序截图整理，记录画板的 3 种初始状态与各控件
> 的精确位置，供自动校准（`toolbar_probe.py`）的控件识别与坐标定位使用。
> 截图存于 `docs/小程序UI/`。

## 1. 截图与窗口尺寸

- 截图逻辑尺寸 **521×979**（用户截图）。
- 后端实际截图为 DPI 放大后的分辨率（历史观测约 720×1251，宽高比例非等比，
  约为 x×1.38 / y×1.28）。**所有坐标必须以「画布相对偏移 + 内容行扫描」为准，
  不得用绝对像素**——窗口尺寸会变，画布锚定窗口顶部、工具行锚定窗口底部。

## 3. 控件位置（图4 `控件标注.png`，展开态）

画布：`(70, 147) → (453, 701)`，即 383×554，底缘 y=701，左缘 x=70。

| 控件 | 标注框色 | x 范围 | y 范围 | 中心点 | 相对画布偏移 |
|------|---------|--------|--------|--------|-------------|
| **撤销** | 红 | 12-147 | 630-702 | (80, 666) | 左缘 +10，底缘 −35（浮在画布内左下角） |
| **折叠** | 绿 | 9-53 | 724-768 | (31, 746) | 左缘 −39（探出左缘），底缘 +45 |
| **画笔 / 橡皮擦** | 蓝 | 120-239 | 718-777 | (180, 748) | 左缘 +110，底缘 +47 |
| **滑杆** | 黄 | 62-515 | 839-899 | (288, 869) | 左缘 −8，底缘 +168 |

工具行（展开态，从左到右）：`折叠钮(绿) 画笔/橡皮擦(蓝) …`，折叠钮贴画布左缘外、
画笔/橡皮擦在其右侧同一行（y≈718-777）。

## 4. 关键洞察（对探测逻辑的影响）

1. **滑杆是上下文相关的，不是常驻控件**：
   - 选中「画笔」时，黄色框区域是**笔宽滑杆**；
   - 选中「橡皮擦」时，黄色框区域是**橡皮擦大小滑杆**。
   - 未选中画笔/橡皮擦时，滑杆可能**不出现**。
   - 因此 `_track_visible()` 用「滑杆轨道是否存在」判断展开/收起态**不可靠**——
     撤销预扫描阶段未选中工具 → 无滑杆 → 轨道检测失败 → 折叠扫描方向被误判。
2. **折叠钮极小**（绿框 x 9-53 ≈ 44px 宽，y 724-768 ≈ 44px 高），贴画布左缘外，
   与画笔/橡皮擦（蓝框 x 120-239）同处一行、左右相邻。
3. **撤销胶囊浮在画布内左下角**（红框横跨画布底缘 y≈701），不是画布下方的独立行。
4. 控件纵向顺序（展开态，从上到下）：
   `撤销(666) → 折叠/画笔/橡皮擦(746-748) → 滑杆(869)`，三者相距约 80px 与 120px。

## 5. 与既有文档的关系

- 本文档的坐标是**用户截图（521×979）实测**，比 `校准目标与难点.md` 中记录的
  499×979 旧值更精确（画布 383×554、折叠钮中心 (31,746)、滑杆中心 (288,869)）。
