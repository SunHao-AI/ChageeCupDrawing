# 差异图诊断与参数调优指南

面向正在使用绘制规划预览的用户，说明如何通过差异图、模拟笔迹等预览图判断规划质量，以及如何调整参数解决常见的漏画、越界、画面发脏等问题。文中所有参数名与范围均来自前端参数面板（图像、路径、节奏三组），默认值为系统出厂值。

## 预览图速览

参数面板每次调整后系统自动重新规划，四张缩略图同步刷新。看图顺序建议为：合成预览判断整体观感，模拟笔迹判断实际绘制效果，差异图定位具体缺陷，目标掩膜确认问题源头是不是掩膜本身。

| 预览图 | 内容 | 用来判断 |
| --- | --- | --- |
| 合成预览 | 原照片叠加模拟笔迹 | 整体还原度、真实观感 |
| 模拟笔迹 | 规划路径按真实笔宽渲染 | 绘画机实际会画成什么样 |
| 差异图 | 目标掩膜与模拟笔迹的逐像素对比 | 哪里漏画、哪里画多了 |
| 目标掩膜 | 二值化后的应画区域 | 问题源头是掩膜还是笔迹 |

## 差异图颜色含义

差异图对比两个对象：目标掩膜（应该画墨的地方）与模拟笔迹（实际会画墨的地方）。

| 颜色 | 含义 | 对指标的影响 |
| --- | --- | --- |
| 黑色 | 命中：目标有墨，笔迹也覆盖到了 | 越高越好 |
| 红色 | 漏画（miss）：目标有墨，笔迹没有覆盖 | 拉低召回率 recall |
| 蓝色 | 越界（spill）：笔迹画到了目标之外的空白区 | 拉低精确率 precision |
| 白色 | 双方都无墨的正常空白 | 无 |

规划结果同时给出精确率、召回率、IoU 三个数值指标，差异图就是这两个指标的可视化版本。红色多则召回率低，蓝色多则精确率低。

## 红色漏画的诊断与调整

红色并不代表"画得不好"这么简单，先分辨红色出现在哪里、以什么形态出现，再决定动哪个参数。

### 形态一：大片实心区域整体发红

目标掩膜里存在连笔宽都盖不住的实心碎块，通常由二值化把浅灰、阴影、噪点烧进了掩膜。此时应该修掩膜，而不是让笔迹去追。

调整方式（按顺序尝试）：

1. 图像模式切换为保真（fidelity）。该模式只保留紧邻真实墨迹的浅像素，对截图、照片类素材的碎线抑制效果最直接。
2. 降低细节保留（detailKeep，默认 0.14，范围 0.05–0.60）。数值越小，被过滤掉的小连通域越多，掩膜越干净。
3. 提高二值阈值（threshold，默认 205，范围 90–230）。阈值越高，进入掩膜的暗区越少。注意对暗背景素材会连带削掉真实线条。
4. 线宽膨胀（lineExpand，默认 0，范围 -2 至 3）调为 -1 或 -2，腐蚀掩膜、抹掉细须。这会整体缩小掩膜，属于修改目标而非补全笔迹，慎用。

需要强调：如果红区本身是掩膜噪点（真机上画出来只会让画面发脏），正确做法就是让它继续红着——通过修掩膜把目标改对，而不是加笔迹去填满。

### 形态二：细线两侧断续发红

掩膜是合理的，但路径规划跟不上细节。

1. 减小简化精度（simplifyPx，默认 0.16，范围 0.1–2.0）。数值越小路径越贴合原形，减少简化带来的偏离。
2. 增大超采样（supersample，默认 3，范围 1–4）。在工作分辨率更高的图上提路径，细线保真更好，代价是规划耗时增加。
3. 增大笔宽（brushWidth，默认 3，范围 1–12）。单笔覆盖变宽直接吃掉细缝，但会同时推高蓝色越界、糊掉相邻细节，适合脸部等大面积区域，不适合发丝。

### 形态三：暗区、填充区内部发红

填充覆盖不足。

1. 增大填充密度（fillDensity，默认 0.82，范围 0.62–1.1，仅拓扑填充策略生效），填充行距更密。
2. 提高目标召回（targetRecall，默认 0.985，范围 0.95–0.998，仅拓扑填充策略生效）。拓扑救援机制会找到漏画像素附近的骨架段补画，直到达到该目标值。提高它会追加更多补偿路径，伴随精确率小幅下降。
3. 确认拓扑救援开关处于开启状态（仅拓扑填充策略有此开关）。关闭后漏画只能靠掩膜质量硬扛。

### 形态四：照片素描策略下大面积发红

照片素描（tone）策略直接消费灰度做等值线分层，不走二值掩膜救援。此时 fillDensity、targetRecall、拓扑救援均不生效。

1. 增大素描层次（hatchLevels，默认 10，范围 6–24）。层次越多，暗部越细腻、笔迹越密。
2. 适当增大笔宽。素描线条本身较细，笔宽过小时相邻等值线之间会露白。

## 蓝色越界的诊断与调整

| 现象 | 原因 | 调整方式 |
| --- | --- | --- |
| 线条两侧均匀泛蓝 | 笔宽大于线条实际宽度 | 减小笔宽；或接受轻微溢出，真机墨水本身会洇开 |
| 目标外围成块泛蓝 | 线宽膨胀为正值导致掩膜外的路径外扩 | lineExpand 调回 0 或负值 |
| 折线、转弯处泛蓝 | 路径简化过度，直线切角越出原形 | 减小 simplifyPx |
| 提高 targetRecall 后蓝区明显增多 | 救援补偿路径放低了包含阈值 | 回调 targetRecall，在召回与精确之间找平衡 |

## 漏画与越界的跷跷板关系

recall 与 precision 相互制约：笔迹加粗、加密、提高救援力度，红色减少的同时蓝色几乎必然增加。调参时建议每改一项就对照一次三指标和差异图，避免按下葫芦浮起瓢。经验上先保证掩膜干净（消除虚假目标），再谈笔迹覆盖，最后才微调 targetRecall 收残余漏画，这个顺序的返工最少。

## 其他常见问题

### 模拟笔迹看着不错，真机画出来却偏脏或偏淡

模拟渲染假设墨水不洇不淡，真机受笔头出墨、纸面、速度影响。处理方向在节奏组：

- 真机线条比模拟粗、洇墨：减小每点延迟（pointDelayMs，默认 1.5 ms）提高移动速度，减少单点积墨；或换出墨更少的笔。
- 真机线条比模拟淡：放慢速度（增大 pointDelayMs），或适度增大笔宽重新规划。
- 短横、点、撇丢失或画不出：开启短笔画保护，必要时增大点击按住（clickHoldMs，默认 20 ms）、下调短笔迹阈值（默认 1.2 px），让短笔画更走点击而非划动。
- 长直线缺中间点出现跳线：开启禁止合并移动事件（NOCOALESCE）。

### 画面内容贴边或被裁切

增大安全边距（safeMargin，默认 4，范围 2–25）。系统会自动取「安全边距」与「笔宽一半加 2」中的较大值，所以大笔宽时实际边距比设置值更大。素材主体不全时检查适配方式：完整包含（contain）留白但保全画面，铺满裁切（cover）撑满杯面但会裁掉边缘。

### 差异图整体偏灰、黑白分不清

目标掩膜本身质量差（原图模糊、对比度低）。先提高对比度（contrast，默认 1.0，范围 0.6–2.2），再考虑换图像模式：自适应（adaptive）适合光照不均的屏幕截图或纸面照片；边缘（edge）只要轮廓不要暗面；抖动（dither）适合大面积渐变的艺术化效果。

### 规划耗时过长

规划通常需要 10–30 秒，超采样调高、素描层次调多、目标召回逼近上限都会显著加长耗时。赶时间可先降 supersample 到 2 快速验证构图，定稿前再调回 3–4 精修。

### 各策略下某些参数不生效

填充密度、拓扑救援、目标召回只在拓扑填充策略下显示和生效；素描层次只在照片素描策略下生效；扫描行距（legacyRowStep，默认 3）只在水平扫描策略下生效。面板已按策略自动隐藏无关项，若从预设导入过参数，切换策略后注意确认相关项的当前值。

## 推荐调参流程

1. 先看图：差异图红色是大片实心（修掩膜）还是细线断续（调路径）。
2. 掩膜层：图像模式选保真，视素材微调二值阈值与细节保留，对照目标掩膜确认干净。
3. 笔迹层：笔宽保持校准值 3 起步，暗区发红加填充密度，细线发红降简化精度。
4. 补偿层：开拓扑救援，目标召回从 0.985 起步，残余红区明显再升至 0.99。
5. 每步核对精确率、召回率与蓝色区域，两者同时满意后切到模拟笔迹确认观感，再执行绘制。
